# Changing the wire contract

The OpenAPI document is the contract. Everything else is generated from it or implements it.

1. **Check it is additive.** v1 allows new operations and new optional fields. Removing an operation or property, or adding a required field, is breaking: stop and ask.
2. **Edit** `packages/protocol/openapi/openapi.yaml`. Search for a neighbouring operation and copy its shape (problem responses, security, cursor parameters). Do not read the whole file.
3. **Generate**: `pnpm generate`. This rewrites `packages/client-ts/src/generated.ts` and `clients/swift/Sources/EmulatorContentClient/GeneratedModels.swift`. Never edit those by hand.
4. **Implement** the route in `apps/server/src`. Authenticate, decide access, then touch storage. Catalog queries go in `packages/database`.
5. **Test** in `apps/server/test/` with generated bytes. `pnpm build && node --test apps/server/dist/test/<name>.test.js`.
6. **Snapshot**: `pnpm update-surface`, then `pnpm check-drift` must pass.
7. **Clients**: use the new field in `apps/web` or the hand-written part of `clients/swift` if this change is for them. Run `swift test --package-path clients/swift` when Swift sources changed.
8. **Document** it in `docs/protocol/client-integration.md` if an app developer needs to know.

A list endpoint should return what a grid needs (title, system, artwork reference, revision) in the page itself. If a client would need one request per row, the contract is not done.
