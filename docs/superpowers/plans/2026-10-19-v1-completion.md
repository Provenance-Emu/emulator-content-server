## Global Constraints

- One logical change per pull request, with tests for the behavior you change.
- New schema is a new numbered SQL migration. Do not edit a migration that has shipped.
- `packages/protocol/openapi/openapi.yaml` is the contract. Regenerate with `pnpm generate` when it changes; preserve additive v1 compatibility.
- Use generated bytes in tests. Do not commit ROM, BIOS, disc, or save files.
- Never log bootstrap tokens, bearer tokens, passwords, or authorization headers.
- Keep the primary checkout and local main untouched. Only the controller creates PRs and merges, using merge commits after automated checks pass.
- No release tag, package publication, relay, STUN, TURN, automatic forwarding, app adapters, or signing/JIT execution.
- Disc-container providers and browser playback are included in 1.0 by the user's scope answer. Track their implementation separately and do not claim them shipped before they merge.

## Review Focus

- A rejected upload must preserve its committed offset and staging bytes, including when its declared total disagrees with the body.
- Revoked or expired grants and reader roles must not acquire administrative access.
- Reusing an idempotency key with changed content must return the contract's conflict response.
- An oversized relative path must fail with HTTP 400 before upload completion changes catalog/blob state; the existing 1,024-character boundary remains unchanged.
- A VPN or reverse proxy must not inherit loopback/LAN authority; examples must preserve bearer authentication and explicit TLS policy.
